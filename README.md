Bus Management System

A desktop-based Bus Management System developed using Java Swing and MySQL.

Project Description

This project helps manage bus details, employee details, and passenger bookings through an easy-to-use interface.

Technologies Used

- Java
- Java Swing
- Apache NetBeans IDE
- MySQL
- JDBC

Main Modules

- Admin Login
- User Login
- Add Bus Details
- Manage Bus Details
- Employee Management
- Bus Booking
- Assign Bus

Database

MySQL is used to store and manage project data.
